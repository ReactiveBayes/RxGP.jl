RxGPs.jl

Sparse Gaussian process factor nodes for variational message passing on factor graphs.

RxGPs brings variational sparse Gaussian processes (VSGPs) to RxInfer.jl. A GP enters a model as one factor node per observation, connected to shared inducing variables, a noise precision and the kernel hyperparameters, and inference is message passing on the factor graph, alongside whatever else the model contains.

Why RxGPs?

Gaussian processes are flexible non-parametric models, but exact inference costs $O(N^3)$ in the number of observations. Sparse variational approximations reduce this with a small set of inducing points, yet putting a sparse GP inside a larger probabilistic model, a state-space model say, usually takes an inference algorithm derived by hand.

RxGPs packages the sparse GP into factor nodes, UniSGP, UniSGP_dID and MultiSGP, whose message passing rules are declared with MessagePassingRulesBase.jl and run by RxInfer's engine. So you can:

  • compose GP components with any other model element, in GraphPPL.jl's model syntax;
  • infer the inducing variables, the noise precisions and uncertain inputs jointly by variational message passing, with no derivation by hand;
  • observe function values, gradients, or both, through UniSGP_dID's linear operators.

Features

  • Three sparse GP factor nodes, with message passing rules towards every edge:
    • UniSGP: a scalar function of a D-dimensional input;
    • UniSGP_dID: a linear operator of the function, such as its gradient, or the function and its gradient together;
    • MultiSGP: a vector-valued function.
  • Kernels from get_simple_kernel_and_params: squared exponential (:SE), mixtures of them (:SEn), spectral mixtures (:SMn) and their sums (:SEn_SMn).
  • Kernel derivatives for the gradient operators, by automatic differentiation (:AD) or in closed form for the squared exponential (:AN).
  • Uncertain inputs: kernel expectations by Gauss–Hermite cubature (the default), the spherical-radial cubature srcubature or the generalised unscented transform GenUnscented.
  • Prediction at new inputs with predict_GP.
  • Hyperparameter learning: the M-step objectives and their gradients, neg_log_backwardmess_fast and grad_llh_default!.

The package

RxGPs.RxGPs — Module
RxGPs

Sparse Gaussian process factor nodes for variational message passing with RxInfer.jl: a GP enters a model as one factor per observation, and inference over its inducing variables, noise, hyperparameters and uncertain inputs is message passing on the factor graph.

  • UniSGP: a scalar function of a D-dimensional input.
  • UniSGP_dID: a linear operator of the function, such as its gradient, observed in $\mathbb{R}^P$.
  • MultiSGP: a vector-valued function, through the intrinsic coregionalisation model.
  • UniSGPMeta, built by get_UniSGPMeta, and MultiSGPMeta: their algorithms, which carry the kernel, the inducing inputs and the approximation method.
  • predict_GP: the posterior predictive distribution; grad_llh_default! and its siblings: the M-step for the kernel hyperparameters.

The nodes and rules are declared with MessagePassingRulesBase.jl.
