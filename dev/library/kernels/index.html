Kernel specification

RxGPs builds on KernelFunctions.jl and provides utilities for constructing parameterised kernels, computing their gradient and Hessian operators, and initialising hyperparameters.

Building a kernel

RxGPs.get_simple_kernel_and_params — Function
get_simple_kernel_and_params(D; kernel_spec = :SE, num_SE = 1, num_SM = 1,
                             independent_SE_lengthscales = true) -> (kernel, θ_init, dim_θ)

A kernel constructor kernel = θ -> k for inputs of dimension D, its initial hyperparameters and their number. Every hyperparameter is unconstrained: the kernel applies a softplus to it, so a weight or lengthscale is $\log(1 + e^{\theta_i})$, and θ_init puts every one near 1.

Kernels and the layout of θ

  • :SE: a weighted squared exponential, [weight; lengthscales], with D lengthscales or, with independent_SE_lengthscales = false, one.
  • :SEn: a sum of num_SE of them; with independent lengthscales θ holds each component's [weight; D lengthscales] in turn, otherwise all weights and then all lengthscales.
  • :SMn: a spectral mixture of num_SM components, [weights; scales; means], the last two as D×num_SM matrices by column.
  • :SEn_SMn: the sum of the two, the :SEn part first. With shared lengthscales its :SEn part alternates weight and lengthscale.

An unknown kernel_spec is an ArgumentError.

Example

kernel, θ, dim_θ = get_simple_kernel_and_params(2; kernel_spec = :SE)   # dim_θ == 3
k = kernel(θ)                                                          # a KernelFunctions.jl kernel
source

This function returns a tuple (kernel_fn, θ_init, dim_θ) where:

  • kernel_fn(θ) returns a KernelFunctions.Kernel instance parameterised by θ.
  • θ_init is a vector of initial hyperparameters (in softplus-transformed space).
  • dim_θ is the total number of hyperparameters.

Supported kernel families:

kernel_specDescriptionParameters per component
:SESingle squared-exponential1 + D (variance + lengthscales) or 2 (shared lengthscale)
:SEnSum of num_SE SE kernelsnum_SE × (1 + D) or num_SE × 2
:SMnSum of num_SM spectral-mixture componentsnum_SM × (1 + 2D)
:SEn_SMnSum of SE and SM componentsCombined

The independent_SE_lengthscales flag controls whether each input dimension gets its own lengthscale (true, default) or all dimensions share one (false).

num_SE and num_SM (both 1 by default) are keywords of get_simple_kernel_and_params: the number of squared-exponential and spectral-mixture components. Its docstring gives the order of the hyperparameters in θ for each family.

Gradient and Hessian kernel functions

For derivative observation models (:grad and :joint_fn_grad operators), RxGPs needs the gradient and Hessian of the kernel with respect to the input:

RxGPs.get_gradient_Kxu_fn — Function
get_gradient_Kxu_fn(D; kernel, kernel_spec = :SE, mode = :AD, independent_SE_lengthscales = true)

A function (x, θ, Xu) -> Matrix, the gradient of the cross-kernel $\nabla_x k(x, X_u)$ (D×M), for the gradient operators of get_UniSGPMeta. mode = :AD differentiates kernel with ForwardDiff and works for every kernel family; mode = :AN uses the closed form of the squared exponential, for kernel_spec :SE or :SEn only. A scalar input is taken as a 1-vector.

source
RxGPs.get_gradient_Kxx_fn — Function
get_gradient_Kxx_fn(D; kernel, kernel_spec = :SE, mode = :AD, independent_SE_lengthscales = true)

A function (x, θ) -> Matrix, the mixed second derivative of the auto-kernel $\nabla_x \nabla_{x'} k(x, x')$ at $x' = x$ (D×D): the prior covariance of the GP's gradient. The modes are those of get_gradient_Kxu_fn.

source

These are called internally by get_UniSGPMeta when operator is :grad or :joint_fn_grad. You only need to call them directly for advanced custom setups.

Modes:

ModeDescriptionSupported kernels
:ADAutomatic differentiation via ForwardDiff.jlAll kernel families
:ANClosed-form expressions, faster than automatic differentiation:SE, :SEn only
