Meta objects

Meta objects carry the configuration and precomputed data that the GP factor nodes need during message passing. They are the nodes' algorithms: a model gives one to a node with where { algorithm = meta }, or to every node of a kind with @algorithm. They are immutable and hold no working memory, so one meta may be shared by every node of a model.

UniSGPMeta

UniSGPMeta is used with both UniSGP and UniSGP_dID nodes. It stores:

  • The approximation method (e.g. GenUnscented)
  • The mean function, kernel, and inducing point locations
  • Precomputed kernel matrices and Cholesky factors
  • The operator-specific functions (Lm_fn, Kxu_fn, Kxx_fn) for identity, gradient, or joint operators
RxGPs.UniSGPMeta — Type
UniSGPMeta

The algorithm of the UniSGP and UniSGP_dID nodes, which a model gives them with where { algorithm = meta } or @algorithm. Construct it with get_UniSGPMeta.

It is immutable and holds no working memory, so one instance may be shared by every node of a model, and by models running on several threads.

Fields

  • method: the approximation method for the kernel expectations over an uncertain input.
  • mean_fn: the prior mean function $m(x)$.
  • Xu: the M inducing inputs.
  • Lm_fn: x -> the operator applied to the mean, a vector of length P.
  • Kxx_fn: (x, θ) -> the operator applied to both arguments of the kernel at (x, x), P×P.
  • Kxu_fn: (x, θ, Xu) -> the operator applied to the cross-kernel, P×M.
  • KuuF: the Cholesky factorisation of $K_{uu}$ at the θ the meta was built with.
  • kernel: the kernel constructor θ -> k.
  • dims_input, dims_output, dims_theta: D, P and the number of hyperparameters.
Note

The rules towards out, v and w (or Wg) use KuuF, fixed at the meta's θ, with the kernel at the mean of q(θ). Keep the two equal: build a new meta when θ changes.

Construction

The recommended way to create a UniSGPMeta is via get_UniSGPMeta:

RxGPs.get_UniSGPMeta — Function
get_UniSGPMeta(D; mean_fn, kernel, Xu, θ, method = ghcubature(21), operator = :fn,
               kernel_spec = :SE, mode = :AD, independent_SE_lengthscales = true,
               Lm_fn = nothing, Kxu_fn = nothing, Kxx_fn = nothing) -> UniSGPMeta

The meta of the UniSGP and UniSGP_dID nodes for inputs of dimension D: what a model gives them as their algorithm, with where { algorithm = meta } or @algorithm.

Keywords

  • mean_fn: the prior mean function $m(x)$, a scalar function of the input.
  • kernel: the kernel constructor θ -> k, a KernelFunctions.jl kernel; see get_simple_kernel_and_params.
  • Xu: the M inducing inputs, numbers for D = 1 or vectors of length D.
  • θ: the kernel hyperparameters at which $K_{uu}$ is factorised, a vector or a PointMass.
  • method: the approximation method for the kernel expectations over an uncertain input: ghcubature(p), srcubature() or GenUnscented(). With observed inputs it is not used.
  • operator: the linear operator applied to the GP for UniSGP_dID: :fn (the function, P = 1), :grad (its gradient, P = D) or :joint_fn_grad (both stacked, P = 1 + D). UniSGP uses :fn.
  • kernel_spec, mode, independent_SE_lengthscales: how the operator's kernel derivatives are built: the kernel family, :AD (automatic differentiation) or :AN (analytic, for :SE and :SEn only), and whether each input dimension has its own lengthscale.
  • Lm_fn, Kxu_fn, Kxx_fn: a custom operator, given as its three functions (see UniSGPMeta); they replace the ones operator builds.
Note

$K_{uu}$ is factorised once, at the θ given here, with the package's $K_{uu}$ jitter. When θ changes, for example between the EM iterations of the README, build the meta again.

Example

kernel, θ, _ = get_simple_kernel_and_params(1; kernel_spec = :SE)
meta = get_UniSGPMeta(1; mean_fn = x -> 0.0, kernel = kernel, Xu = collect(range(-4, 4; length = 10)), θ = θ)

MultiSGPMeta

MultiSGPMeta is used with the MultiSGP node.

RxGPs.MultiSGPMeta — Type
MultiSGPMeta(method, Xu, Kuu_inverse, kernel)

The algorithm of the MultiSGP node, which a model gives it with where { algorithm = meta } or @algorithm.

Arguments

  • method: the approximation method for the kernel expectations over the input, such as srcubature() or ghcubature(p).
  • Xu: the M inducing inputs, vectors of the input dimension.
  • Kuu_inverse: $K_{uu}^{-1}$, M×M, for the kernel at the current hyperparameters.
  • kernel: the kernel constructor θ -> k.

It is immutable: the kernel expectations the rules compute in place live in each rule's scratch, which the engine keeps per node, so one instance may be shared by every node of a model. As for UniSGPMeta, build a new one when the hyperparameters change.

Example

kernel = θ -> θ[1] * with_lengthscale(SEKernel(), θ[2])
θ = [1.0, 1.0]
Xu = [[x, y] for x in 1.0:3.0 for y in 1.0:3.0]
meta = MultiSGPMeta(srcubature(), Xu, inv(kernelmatrix(kernel(θ), Xu) + 1e-8I), kernel)
